# Security

Gitr runs Git commands on your repositories and can hold access to your Git hosts, so a hole in it can matter.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub's advisory form](https://github.com/etiennedelange/gitr/security/advisories/new) instead. Include the version, your platform and the steps to reproduce.

This is a one-person project, so there's no fixed response time. A confirmed issue gets fixed in the next release, and the advisory is published once that release is out.

## Supported versions

Only the latest release gets fixes.
